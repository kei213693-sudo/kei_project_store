Detailed Description

Non Volatile Data Storage (NVDS)

Note
  • Each TAG has a maximum length of 256 bytes
  • All the TAG header structures and TAG data contents are stored consecutively without gaps (as would be a structure with pragma packed)
  • PUT, DEL and GET action are provided.

Look for a specific tag and return, if found and matching (in length), the DATA part of the TAG.

◆ nvds_put()

uint8_t nvds_put ( uint8_t  tag,
nvds_tag_len_t  length,
uint8_t *  buf 
)

This function adds a specific TAG to the NVDS.

Steps:

  1. parse all the TAGs to:
    1. calculate the total size of all the valid TAGs
    2. erase the existing TAGs that have the same ID
    3. check if we can use the same TAG area in case of an EEPROM
    4. check that the TAG is not locked
  2. if we have to add the new TAG at the end fo the NVDS (cant use same area):
    1. allocate the appropriate amount of memory
    2. purge the NVDS
    3. free the memory allocated
    4. check that there is now enough room for the new TAG or return NO_SPACE_AVAILABLE
  3. add the new TAG
Parameters
[in]tagTAG to look for whose DATA is to be retrieved
[in]lengthExpected length of the TAG
[in]bufPointer to the buffer containing the DATA part of the TAG to add to the NVDS
Return values
NVDS_OKNew TAG correctly written to the NVDS
NVDS_PARAM_LOCKEDNew TAG is trying to overwrite a TAG that is locked
NVDS_NO_SPACE_AVAILABLENew TAG can not fit in the available space in the NVDS
