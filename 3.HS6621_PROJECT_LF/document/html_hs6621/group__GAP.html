Detailed Description

Generic Access Profile.

The GAP module is responsible for providing an API to the application in order to configure the device in the desired mode (discoverable, connectable, etc.) and perform required actions (scanning, connection, pairing, etc.). To achieve this, the GAP interfaces with both the "SMP", "L2C" and the "CONTROLLER"
