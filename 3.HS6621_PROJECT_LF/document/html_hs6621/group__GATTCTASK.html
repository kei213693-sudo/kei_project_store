Detailed Description

Handles ALL messages to/from GATT Controller block.

The GATTCTASK is responsible for managing the messages coming from the attribute layer and host-level layers for dedicated connection. The task includes services and characteristic discovery, configuration exchanges and attribute value access operations (reading, writing, notification and indication).

Messages may originate from "ATTC", "ATTS", "GAP" and Application.
