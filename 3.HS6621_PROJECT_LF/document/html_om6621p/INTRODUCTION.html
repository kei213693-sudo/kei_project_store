Introduction

The OM6621P is a power-optimized true system-on-chip (SoC) solution for both Bluetooth low energy and proprietary 2.4-GHz applications. It integrates a high performance and low power RF transceiver with Bluetooth baseband and rich peripheral IO extension. OM6621P also integrates a power management to provide high-efficient power management. It targets 2.4-GHz Bluetooth low energy systems, proprietary 2.4-GHz systems, Human-Interface Devices (keyboard, mouse, and remote control), sports and leisure equipment, mobile phone accessories and consumer electronics.

OM6621P on-chip Bluetooth system compliant with version 5.1, support all of Bluetooth standard 5.1 feature.

The chip integrates up to 128MHz high-performance MCU, DMA, GPIO, I2S, I2C, SPI, UART, TIMER, RTC, watch dog, supports 32Mhz external crystal, integrates multi-purpose 12 bit ADC，AUDIO ADC

The OM6621P integrates on chip 256KB ROM, 392K SRAM and supports user defined IDE system, on chip SFLASH MCU development and JTAG software upgrade.

Features

RF

  • -96dBm sensitivity @1Mbps
  • -93dBm sensitivity @2Mbps
  • -96dBm sensitivity @500Kbps
  • -101dBm sensitivity @125Kbps
  • TX power -20~7dBm
  • RSSI (1db resolution)

CPU

  • ARM® Cortex™-M4F, max 128MHz
  • Serial Wire Debug (SWD)

Memory

  • 392KB SRAM
  • 256KB ROM
  • 4Mb/8Mb/16Mb SFLASH

Clocks

  • 32MHz crystal, 32MHz RC, 32.768KHz crystal, 32.768KHz RC

Link Controller

  • BT 5.1 LE PHY, link controller
  • Proprietary 2.4-GHz link controller
  • AoA/AoD

Power Management

  • Voltage range: 2.7V~3.6V
  • Charger input voltage: 4.5V~5.5V
  • Peak current: RX 6mA, TX 5.5mA@0dBm
  • Deep-sleep current: 2uA (IO wake-up)
  • Integrated DCDC BUCK Converter
  • Integrated charger circuit of Li-battery

Software

  • Full compliant with BLE version 5.1, complete power-optimized stack, including controller and host
  • Supports BT mesh network
  • Support BLE sample applications and profiles
  • Support HCI controller interface
  • Support OTA

Peripherals

  • Up to 50 GPIOs
  • 4 DMAs, 2 UART, I2S, 3 I2C
  • 2 SPI, 3 flash controller
  • Support DSPI/QSPI LCD display
  • Support QSPI PSRAM
  • 3 Timers, 3 QDECs
  • Watchdog, RTC
  • Key-board controller
  • 8 channel 12-bit ADC，max 2Msps
  • 16 bit ADC, SNR 93dB
  • Hardware AES
  • Random number generator
