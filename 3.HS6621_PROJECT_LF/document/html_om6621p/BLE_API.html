BLE API

Ble stack API and type definition.

Common APIs and corresponding type definitions in the protocol stack, non-common macro definitions, etc. Please refer to the corresponding .h file in the source code.

BLE Stack Message Interface：

  1. GAPM Message
  2. GAPC Message
  3. GATTM Message
  4. GATTC Message
  5. L2CC Message

‍Messages sent to the above Task are all ending with _CMD, _CFM or _REQ.
When the Task replies, the message ends with _IND, _CMD_EVT or _RSP.
See Build and Send Message for how to create ad send a message.
Commonly used message sequence charts please reference to Message Sequence Charts .

Task and Message：

The task is declared in Task and Message, and the creation of the message and task and the corresponding operation interface are provided.

Profiles and ATT：

Profiles and ATT define the interface for creating and using profiles; ATT defines the relevant interfaces for creating GATT services.

Non Volatile Data Storage (NVDS)：

The interface that stores system or user data into the flash is defined in NVDS.

Application Host Interface(AHI)：

AHI defines the data format when using the AHI to communicate with the chip.

Build and Send Message

RW protocol stack adopts task-based working mode. There are multiple tasks in the system (including the default tasks of user and protocol stack). Message mechanism communication is adopted between tasks.

When create a task, must call KE_MSG_ALLOC (id, dest, src, param_str) or KE_MSG_ALLOC_DYN (id, dest, src, param_str, length)

  • Dest, SRC: the unique identification of task, which is defined by the protocol stack. Generally, users do not need to define it manually. See KE_TASK_TYPE
  • id: Each KE_TASK_TYPE has a corresponding set of ke_msg_handler. ke_msg_handler.id is the message id, TASK_FIRST_MSG (task_id) can be used to define the first message corresponding to a task (task_id type is TASK_API_ID, not KE_TASK_TYPE). ke_msg_handler.func is a function pointer of type ke_msg_func_t, which is used to process the corresponding ke_msg_handler.id for example, the message processing function of GAPC task is defined as:
    KE_MSG_HANDLER_TAB(gapc)
