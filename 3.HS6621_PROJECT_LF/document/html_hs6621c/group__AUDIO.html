Detailed Description

Audio.

The HS6621 has an audio PGA and ADC inside. The structure is as shown below, the PGA has a single input, which can be switched from GPIO[0] to GPIO[6]. The PGA gain varies from -14dB to 4dB in line-in mode, and from -3dB to 15dB in mic-in mode. The PGA cascades ADC，dynamic range is 95.7dB, SNDR is 75.8dB, and SNR is 90.6dB.
