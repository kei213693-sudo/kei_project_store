BLE Example

There are several reference instances in the examples directory that user can refer to before writing an application.

一、Directory description

Directory description
common This directory contains the functions of advertising, privacy, whitelist, security setting。
ble_app_simple_server This is a simple server example。
ble_app_watch This example implements watch.
ble_app_rc This example implements a voice remote control.
ble_app_keyboard This example implements HID keyboard using HID profile.
ble_app_mouse This example implements HID mouse using HID profile.
ble_app_mesh This example implements mesh network.
ble_app_hci_ahi This example implements AHI interface, use uart connect with PC，completes BQB or tests.
ble_app_central This example for multi-connect and central using the pass-through profile (TSPP) defined by Onmicro.
ble_app_central_and_peripheral This example for multi-connect, central and peripheral using the pass-through profile (TSPP) defined by Onmicro.
ble_app_nordic_dfu This is a OTA device firmware update profile for update APP, Patch and patch, which compatible Nordic app
ble_app_wechat This example implements wechat.
ble_app_ancs This is an example of ANCS for IOS, appling GATT client，obtaining notification information from IOS and so on.

note: please click on the specific directory fro details。
