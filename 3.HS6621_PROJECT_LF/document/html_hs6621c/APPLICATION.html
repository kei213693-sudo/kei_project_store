SDK Directory

SDK directory is as show below:

▸ coroutine/             Some helper functions, such as log_debug(), fifo, co_time(), co_assert(), etc
▸ document/              SDK documents
▾ examples/              SDK examples
  ▸ ble_app_{name}/          BLE examples
  ▸ common/                  Common files of BLE examples
  ▸ peripheral/              Peripheral driver examples
▾ external/              Third-party source files
▾ hardware/              Hardware driver
  ▸ cfg/                     Flash config interface
  ▸ cmsis/                   ARM CMSIS driver and its source code
  ▸ mbr/                     MBR for Bootloader
  ▸ peripheral/              Peripheral driver and its source code
  ▸ sys/                     Hardware header
▸ include/               Some include files
▸ lib/                   Library file
▸ stack/                 BLE stack files

Sample Projects

To help create user application, many sample projects in SDK have been created to start with, such as ble_app_simple_server and some ble related demo sample projects. Through studying sample projects, customers can easily get familar with SDK. All sample projects have been configured and memory layout in scatter file is also modified to comply with HS6621C SOC.

Taking ble_app_simple_server application as an example below, it shows how to start developing the customized user application by the sample project. The snapshots are captured with current SDK, and may subject to change due to SDK upgrade.

ble_app_simple_server Sample Project

Source files in ble_app_simple_server project are currently categorized into several groups as below:

Group Description
startup System startup files
main Main files
app APP directory includes the pxp user application implementation.
profile Profile directory includes BLE profiles or services used by the sample application.
stack BLE stack directory

File name Description:

File Description
startup_hs6621.s System startup file
main.c main file
retarget.c retarget for printf
app.c BLE application main file
app_adv.c BLE application advertising file
app_sec.c BLE application security file
app_simple_server.c BLE application profile file
simple_server.c BLE profile simple server file
simple_server_task.c BLE profile simple server's task file
remem.c BLE stack HEAP file

The sample project may upgrade together with the SDK, and to better utilize the upgraded sample code, newly added user code is suggested to being organized and modularized. More detail information on each sample project could be found in its user manual.
