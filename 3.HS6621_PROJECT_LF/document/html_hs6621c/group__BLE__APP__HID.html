一、Same File Description

File Description
app_batt.* Battery Profile，get battery value via call app_batt_send_lvl(uint8_t batt_lvl) function, and then send to central.
app_dis.* Device Info Profile，contains SpecificationID, VendorID, ProductID, Version and so on.
app_hid.* HID Profile，Device description.
