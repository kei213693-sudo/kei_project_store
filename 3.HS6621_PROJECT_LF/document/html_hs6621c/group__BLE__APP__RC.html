一、Codec

This example uses sbc, SBC is mandatory to support in this profile. The SBC specification is a part of the Bluetooth specification. please ref 《A2DP Spec 1.3》

1.References [1] sbc_math.h [2] sbc_tables.h [3] sbc_bluez.h [4] sbc_bluez.c

三、Interface of TSPP。

TSPP(Transport profile) defined by Onmicro，implements transport function.

  • 1. set size of cache buffer and the uuid of service.

app_tspp_server.c, in app_tspp_server_add_service function.

// Parameters for the database creation
struct tspp_server_db_cfg
{
uint16_t connect_num; // <= BLE_CONNECTION_MAX
uint16_t fifo_size; // profile fifo size
uint8_t svc_type; // type=0; 16bit uuid; type=1:128bit uuid; type=2;
struct tspps_sdp_svc svc; // the uuid of service.
};

  • 3.send data

void app_tspp_server_send_data(uint8_t conidx, uint8_t* pdata, uint16_t len);

send data to phone.

Parameters
[in]conidxconnect index
[in]pdatasend data buffer
[in]lensend data len

Note：

  • when buffer empty, TSPP send TSPP_SERVER_BUFFER_EMPTY event；
  • when buffer full, TSPP send TSPP_SERVER_BUFFER_FULL event, and discard current package。
  • If do not discard package, you can wait TSPP_SERVER_BUFFER_EMPTY and the send next package。
